Źródło: Meta, Instagram Help Center — „Your Profile"

Korpus: ALFA_ORACLE_KNOWLEDGE_CORPUS · kategoria: platformy-meta
Data weryfikacji: 2026-10-23

## Czym jest profil

Profil na Instagramie to publiczna (lub prywatna) wizytówka konta.
Zbiera w jednym miejscu:

1. **Treści użytkownika** — zdjęcia, filmy, rolki, relacje (wyróżnione).
2. **Ustawienia konta** — prywatność, powiadomienia, dane logowania.
3. **Relacje** — lista obserwujących i obserwowanych.

## Elementy profilu

| Element | Opis |
|---|---|
| Zdjęcie profilowe | Awatar widoczny publicznie |
| Nazwa użytkownika | Unikalny @handle (login) |
| Nazwa wyświetlana | Dowolna, nie musi być unikalna |
| Bio | Krótki opis (limit znaków), może zawierać linki |
| Linki | Do 5 linków zewnętrznych w bio |
| Siatka postów | Chronologiczna siatka treści |
| Wyróżnione relacje | Stałe Stories przypięte nad siatką |
| Oznaczenia | Posty, na których ktoś oznaczył konto |

## Typy kont

- **Osobiste** — domyślne, pełna prywatność opcjonalna.
- **Kreatora** — statystyki, kategorie, filtry skrzynki DM.
- **Firmowe** — statystyki, reklamy, przyciski kontaktowe,
  dostęp do Meta Business Suite i integracji API.

## Prywatność

- Konto publiczne: treści widzi każdy.
- Konto prywatne: treści tylko dla zatwierdzonych obserwujących.
- Oznaczenia i wzmianki można ograniczyć lub wymagać zatwierdzenia.

## Powiązania z Meta Account Center

Profil Instagram łączy się przez Accounts Center z Facebookiem
i (opcjonalnie) z ekosystemem urządzeń Meta — to ta sama tożsamość,
która obejmuje okulary Ray-Ban Meta i Meta Model API
(patrz: `lib/core/config.dart`).

## Notatki projektowe (ALFA × Meta)

- Konto firmowe/kreatora jest wymagane dla integracji API
  (Instagram Graph API — publikacja, statystyki, DM dla firm).
