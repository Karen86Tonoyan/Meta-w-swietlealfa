# Wiedza: Konto profesjonalne na Instagramie (firmowe / kreatora)

Źródło: Meta, Instagram Help Center — „Set up a professional Instagram account"
(https://help.instagram.com/502981923235522/)
Korpus: ALFA_ORACLE_KNOWLEDGE_CORPUS · kategoria: platformy-meta
Data weryfikacji: 2026-10-23

## Dla kogo

- **Konto firmowe (Business)** — sklepy, lokalne firmy, marki, organizacje, usługodawcy.
- **Konto kreatora (Creator)** — osoby publiczne, twórcy treści, artyści, influencerzy.

## Co daje konto profesjonalne

- Panel profesjonalny (statystyki / insights, wzrost)
- Tworzenie reklam
- Kwalifikowalność do narzędzi monetyzacji
- Zarządzanie wiadomościami (skrzynka z filtrami)
- Wymagane dla Instagram Graph API (integracje)

## WAŻNE ostrzeżenia

1. **Konto prywatne → profesjonalne = staje się PUBLICZNE.**
   Wszystkie oczekujące prośby o obserwację zostaną automatycznie zaakceptowane.
2. Powrót do konta osobistego odcina dostęp do reklam i części narzędzi
   oraz odłącza powiązaną Stronę na Facebooku.
3. Jednocześnie można być zalogowanym na maks. 10 kont Instagram.

## Jak włączyć (aplikacja mobilna)

1. Profil (prawy dolny róg) → ☰ Więcej → Ustawienia i aktywność.
2. Sekcja „Dla profesjonalistów" → **Typ konta i narzędzia**.
3. **Przełącz na konto profesjonalne** → wybierz kategorię.
4. Wybierz **Twórca** albo **Firma** → Dalej.
5. Opcjonalnie: dane kontaktowe firmy (można pominąć),
   połączenie ze Stroną na Facebooku (opcjonalne).

## Jak włączyć (przeglądarka)

1. ☰ Więcej → Ustawienia → „Dla profesjonalistów" → Typ konta i narzędzia.
2. Przełącz na konto profesjonalne → Twórca / Firma → Dalej → kategoria → Gotowe → Kontynuuj.

## Widoczność danych firmowych

Edytuj profil → „Wyświetlanie profilu" / „Publiczne informacje o firmie":
- można ukryć etykietę kategorii,
- można ukryć dane kontaktowe.

## Zmiana typu konta

Możliwa w każdej chwili: Ustawienia → Typ konta i narzędzia → Typ konta
→ Przełącz typ konta.

## Notatki projektowe (ALFA × Meta)

- Profil ALFA na Instagramie: jeśli ma publikować przez API (Graph API) —
  **wymagane konto firmowe** + połączona Strona FB.
- Cerber pilnujący profilu IG powinien dodać sygnał: `account_type_changed`
  (przejście prywatne→publiczne przy zmianie na profesjonalne to zmiana
  powierzchni ekspozycji — kandydat do grafu wiedzy).
